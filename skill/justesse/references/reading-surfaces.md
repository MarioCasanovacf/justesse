# Reading surfaces

Documentation, guides, articles, help, changelogs, and other long-form pages where the reader's
success is understanding something. Structure for comprehension first; only then make the reading
experience worth staying in.

Choose this mode from the requested surface, not from the product. A developer tool's landing page
is still marketing; that same tool's documentation is a reading surface. A documentation index is
for finding and understanding, not for converting, so do not restyle it into an acquisition page.

## Structure for comprehension

- Let the heading hierarchy be the argument's outline. A reader scanning only the headings should
  reconstruct the shape of the content; a heading that exists for rhythm rather than meaning breaks
  that scan.
- Build navigation from that same outline: a table of contents on long pages, stable anchors on
  every section, breadcrumbs or previous/next links where the corpus has an order.
- Assume arrival mid-page. Search and shared deep links drop readers into a section, not at the
  top, so each section carries enough context to orient without rereading from the start.
- Keep the prose measure readable and the line height generous; density on a reading surface serves
  the prose, not component grids. Sidebars, callouts, and metadata must never squeeze the reading
  column below a comfortable measure.

## Evidence inside prose

- Treat figures, tables, and code blocks as evidence with captions or context, not decoration
  between paragraphs. Keep code copyable and horizontally scrollable in its own container.
- When content can go stale, make freshness visible: a version, a date, or an applies-to statement
  near the top, not buried in a footer.
- Distinguish the reference register from the tutorial register. Reference answers "what exactly";
  a tutorial answers "how do I"; mixing them mid-page forces the reader to re-derive which one they
  are in.

## Reading comfort

- Tune contrast for sustained reading at body size, not only for WCAG minimums on isolated labels.
- Keep motion out of the reading path. A reading surface earns almost no animation; what it earns
  is fast anchors, visible focus, and typography that stays comfortable for a thousand words.
